# Vault

Your knowledge base and memory system.

## Folders

- `daily/` — timestamped daily logs (append-only, one file per day)
- `entities/` — people, projects, companies (one page each)
- `topics/` — recurring themes and subjects (one page each)
- `decisions/` — completed decisions by quarter (append-only history)
- `drafts/` — email drafts and responses (active, sent, expired)
- `meetings/` — meeting notes and context
- `research/` — research files, analysis, and learning

## Core Memory Files

See the root `.claude/` folder:

- `memory/SOUL.md` — who I am (my operating principles)
- `memory/USER.md` — who you are
- `memory/MEMORY.md` — active items and pointers (index)
- `memory/core-memories.md` — things you asked me to remember forever
- `memory/HEARTBEAT.md` — what I check on regularly
- `memory/daily/` — timestamped daily logs (one file per day)

---

This vault is append-only for daily logs and decisions. State files get replaced; events get logged.
